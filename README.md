# Public Github repository for the paper : "Geometric scaling of non-consumptive interactions generates sublinear density dependence and reshapes coexistence"
## Authors: Gaurav Baruah, Yogesh Kumar KC
### Affiliations: Centre for Ecological Sciences, Division of Biology, IISc, Bangalore.

##### Operating System: Ubuntu 22.04.5 LTS or Windows 11 ,MacOS 10.13
##### R version: R 4.4.2 -- 4.5.2 (2025-10-31)

##### Required R packages:
 1. deSolve (integrating differential equations),statmod (statistical analysis).
 2. cowplot (visualisation graphics),dplyr (efficient data structuring),readr (data analysis), beepr (data arranging), ggplot2 (plotting graphics), viridis(colors for plotting), nls.multstart (non-linear regressions) minpack.lm, MuMIn (multilevel model selection)

## R and Python Scripts 
1. `Figure_2_IBM.py` :  A Python script  to simulate and plot results of an individual-based model of a foraging phase in a bounded arena. The output is Figure 2 of the manuscript.
2. `Figure_4_niche_overlap_param_sweep.R` : R script to reproduce figure 4 of the main-text.
3. `FIgure_5_MCT.R` : R script to produce figure 5.
4. `figure_6_glv_trait-based.R` : R script to produce figure 6.
